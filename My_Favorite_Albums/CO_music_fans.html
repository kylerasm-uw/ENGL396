Conceptual Overview for Music Fans

Summary and Audience

This page is a conceptual overview for the music fans who want to analyze their music and have minimal to no programming experience. It is intended for users who want to explore their album data without needing to understand how to program or code.

This page will cover what My Favorite Albums is, including what the scope of the software is and what limitations it has. It will also provide a simplified overview of ow the sow the software works. This page will also include useful definitions for terms the reader may not be familiar with.

What is My Favorite Albums

My Favorite Albums is a software application that can be used to analyze albums a user has listened too and provided a rating too. It contains a large amount of ways to accomplish explore this data (see Software Scope). The application is built using the R programming language. It can be run using RStudio, an integrated development environment (IDE) that provides tools to write and run R code.

Software Scope

The My Favorite Albums software offers several features to allow users to analyze their album ratings. These include:

  • Favorite Albums by Year View the top-ranked album for each year within a selected range.
  • Albums from a Specific Year Explore the highest-ranked albums from a particular year.
  • Albums by Artist See how albums from a selected artist are ranked.
  • Favorite Artists See a ranking artists based on a minimum number of album ratings.
  • Compare Artists Displays a comparisons plot of the album ratings of two artists.
  • Vinyl Collection Find highly rated albums that are not owned on vinyl

Software Limitations

The software has some limitations as well. These limitations are below.

  • Non automatic listening tracking The application will not automatically track your listening and update the data. You must manually import your data
  • CSV preparation is required The application will not automatically prepare the CSV for the user. The user is responsible for correctly formatting the CSV
  • No built in spell check If you are too misspell a name of an artist it will treat the two as completely separate artists

How does the software work?

This section provides a simplified overview of how the software works. Including the different parts and how they work together. Readers who are not partically interested in this topic can skip this section.

The Music Data

The application takes in data as a CSV file to store album rating data. This data will be what the application uses to perform its analysis. The actual format will be talked about in more depth in the tasks section.

User Interface

The application uses a shiny interface to let the users interact via a web browsers. This allows users to view results without having to use the native RStudio outputs

Programming Language and Tools

The application uses the programming language R and the IDE Rstudio. Rstudio is used to write and run the R code.

How it all works together

The whole software works together by using the data from the CSV, running code in Rstudio on said data, and outputting a result on the user interface shiny.

Definitions

R (programming language)

R is a programming language commonly used for statistical computing, data analysis, and creating visualizations.

RStudio

RStudio is an integrated development environment (IDE) that provides tools for writing, running, and debugging R code.

IDE (Integrated development environment)

An IDE is an application that contains tools for writing, running, and debugging tools. RStudio is an IDE that is designed for R code. It acts as a single place where a developer can perform all of these functions instead of using multiple applications.
