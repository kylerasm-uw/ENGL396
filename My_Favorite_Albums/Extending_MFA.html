Extending My Favorite Albums

Overview

This guide is for users who have some experience with programming and likely R. This guide explains how to extend my favorite albums by adding a new tab

Prerequisites

  • RStudio and R installed.
  • My Favorite Albums downloaded
  • Basic knowledge of programming.

Adding Your Own Tab

To extend My Favorite Albums, create a new tab that provides an additional way to analyze the album data. Before starting, consider what information your tab will need as input, such as a year, artist, or other selection.

  1. Create a new R file in the main directory. Give the file a name that relates to the function the tab will serve. such as My_Tab.R.
  2. Write a function in your new file that can be called later from app_server.R. This function should perform some analysis on the album data and return a result, such as a list.
  3. Open app.R and add your new file to the list of sourced files. For example: 
    source("My_Tab.R")
  4. Open app_ui.R and add your new tab to the existing tabset. The example below shows the tab panel for Top Albums by Year. 
    tabPanel("Top Albums by Year", htmlOutput("textTopAlbums"),
    selectInput("year", "Choose a year:", all_years),
    actionButton("action_button2", label = "Submit"),
    htmlOutput("textBreak"), tableOutput("year_table"))
  5. Open app_server.R and add code to call the function you created earlier. This code should also generate any HTML needed for headings and display elements. It should as well as connect buttons to their corresponding events. The example below shows how the Top Albums by Year tab is created in app_server.R. 
    output$textTopAlbums <- renderUI({
    HTML("<h2>Top Albums by Year</h2><br>")
})

output$textBreak <- renderUI({
    HTML("<br><br>")
})

observeEvent(input$action_button2, {

    output$year_table <- renderTable({
        return(year_albums(input$year))
    })

})
  6. Run app.R again and verify that your new tab appears. Test any inputs that you created and make the resulting data is correct.
