Conceptual Overview for Programmers

Summary and Audience

This page is a conceptual overview for programmers with some programming experience who may or may not be familiar with R. These readers want to understand how My Favorite Albums work and they potentially want to know how to expand/modify its functionality.

This page will cover the softwares scope including its limitations. It as well will cover the source code structure and how the pieces work together. There also is a section for required libraries and definitions.

What is My Favorite Albums

My Favorite Albums is an interactive web application developed using R and Shiny. It analyzes annual rankings and ratings of albums provided by the user in a CSV file and presents results in a readable fashion. This software provides the UI and r functions allowing a user to only have to provide formatted CSV data. The software is designed in a way such that it is fairly easy to add a new feature set on top of the existing code in the form of a new tab.

Software Scope

The My Favorite Albums software offers these tabs and analysis

  • Number One Albums Displays the number one ranked album per year from a selected date range
  • Top Albums by Year Provides a drop down that allows user to select a year and see their ranking of albums
  • Artists' Albums Provides a drop down to select an artist and displays a sorted list of their albums rated
  • Favorite Artists Displays a ranked ordering of artists with a minimum amount of ranked albums selected by the user.
  • Artist Comparison Provides a plot of year vs rating for two artists.
  • Vinyl Displays a sorted list of all albums above a set rating set by the user.

Software Limitations

The software has some limitations as well. The software does not anatomically track a users listening history. It does not provide any way for the user to upload data after is has been run. It as ]well does not provide any way to clean the data. That is if the data has any errors in its format or spelling no fixes will be made.

  • Fixed CSV Data The application is designed in such a way that it will read a CSV and provide results based on that data. It has no way to update that data. The only way is ofr the user to upload a new CSV
  • Data Consistency is Required The application does not automatically correct spelling or standardize artist names. so if a user presents an incorrect spelling it will be listed as two different artists.

Source Code Structure

The code is structured across several R files. There is an individual file for handling each tab, these files contain one or more function to create the data to populate the tab.

app.R: Entry Point

This app loads all of the required libraries. It as well sources all of the other files. It lastly creates a new Shiny Ui using the UI and Server code.

app_ui.R: User Interface

This file defines the tabs and the UI used for shiny. It defines the dropdowns, the sliders, and the outputs. This file is also the one that loads the data and some data sorting

app_server.R: Server Logic

This file handles the server logic. It connects the outputs of function to the shiny UI display.

Analysis Tab Files

There is an individual file for each tab that will be displayed. Each of these files contains one or more functions that will analyze the data such that is has the required results to be displayed

CSV Data File

How the Components Work Together

Upon startup app.R loads the libraries and source files. The UI reads the CSV, builds the interface, and prepares the choices based ion the data. Shiny displays this UI and runs the server functions. When submit is clicked one of the tba functions is called and the server renders the output.

Definitions

R

R is a programming language commonly used for statistical computing, data analysis, and visualization. In My Favorite Albums, R processes the CSV data, performs calculations, and generates results for display.

Shiny

Shiny is an R package for building interactive web applications. It connects interface elements, such as selection controls, to R code that processes inputs and generates outputs. This allows users to interact with an application through a web browser rather than running each analysis manually.

RStudio

RStudio is an integrated development environment (IDE) that provides tools for writing, running, and debugging R code.

Integrated Development Environment (IDE)

An IDE is a software application that combines tools for software development, such as a code editor, program execution, and debugging. An IDE can make it easier to work on a project, but it is separate from the programming language itself.

Comma-Separated Values (CSV)

CSV is a text format for storing tabular data. Each line represents a record, and commas separate the fields within that record. In My Favorite Albums, the CSV stores album information in columns that the R functions use for filtering, ranking, and calculating summaries.
